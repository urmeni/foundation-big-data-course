====================================================================

GUIDE D'INSTALLATION ET DE CONFIGURATION DE HADOOP 3.4.0 SUR UBUNTU

====================================================================



Ce guide détaille les étapes pour installer Hadoop en mode pseudo-distribué 

(sur un seul nœud/machine) pour des tests locaux.



--------------------------------------------------------------------

ÉTAPE 1 : PRÉREQUIS (JAVA ET SSH)

--------------------------------------------------------------------

Hadoop nécessite Java pour fonctionner, et SSH pour que ses scripts 

puissent lancer les démons locaux sans demander de mot de passe.



1. Mettre à jour les paquets et installer Java et SSH :

   sudo apt update

   sudo apt install default-jdk openssh-server openssh-client -y



2. Générer une clé SSH (sans mot de passe) :

   ssh-keygen -t rsa -P '' -f ~/.ssh/id_rsa



3. Autoriser la clé pour la connexion locale :

   cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys

   chmod 0600 ~/.ssh/authorized_keys



4. Tester la connexion (tapez 'yes' si demandé, puis tapez 'exit' pour quitter) :

   ssh localhost



--------------------------------------------------------------------

ÉTAPE 2 : TÉLÉCHARGEMENT ET EXTRACTION DE HADOOP

--------------------------------------------------------------------

1. Télécharger la version 3.4.0 :

   cd ~

   wget https://downloads.apache.org/hadoop/common/hadoop-3.4.0/hadoop-3.4.0.tar.gz



2. Extraire et renommer le dossier :

   tar -xvzf hadoop-3.4.0.tar.gz

   mv hadoop-3.4.0 ~/hadoop



--------------------------------------------------------------------

ÉTAPE 3 : VARIABLES D'ENVIRONNEMENT (~/.bashrc)

--------------------------------------------------------------------

1. Ouvrir le fichier de configuration du terminal :

   nano ~/.bashrc



2. Ajouter ces lignes à la fin du fichier (Ajustez si nécessaire) :

   export HADOOP_HOME=$HOME/hadoop

   export PATH=$HADOOP_HOME/bin:$HADOOP_HOME/sbin:$PATH



3. Recharger la configuration :

   source ~/.bashrc



--------------------------------------------------------------------

ÉTAPE 4 : CONFIGURATION DE HADOOP

--------------------------------------------------------------------

Il faut modifier 3 fichiers de configuration situés dans ~/hadoop/etc/hadoop/



1. Fichier hadoop-env.sh (Indiquer le chemin de Java) :

   nano ~/hadoop/etc/hadoop/hadoop-env.sh

   # Cherchez ou ajoutez la ligne suivante :

   export JAVA_HOME=/usr/lib/jvm/default-java



2. Fichier core-site.xml (Définir le système de fichiers par défaut) :

   nano ~/hadoop/etc/hadoop/core-site.xml

   # Placez ceci entre les balises <configuration> et </configuration> :

   <property>

       <name>fs.defaultFS</name>

       <value>hdfs://localhost:9000</value>

   </property>



3. Fichier hdfs-site.xml (Définir la réplication à 1 pour une seule machine) :

   nano ~/hadoop/etc/hadoop/hdfs-site.xml

   # Placez ceci entre les balises <configuration> et </configuration> :

   <property>

       <name>dfs.replication</name>

       <value>1</value>

   </property>



--------------------------------------------------------------------

ÉTAPE 5 : FORMATAGE ET DÉMARRAGE DU CLUSTER

--------------------------------------------------------------------

1. Formater le système de fichiers distribué (HDFS) :

   hdfs namenode -format



2. Démarrer HDFS (NameNode, DataNode, SecondaryNameNode) :

   start-dfs.sh



3. Démarrer YARN (ResourceManager, NodeManager) :

   start-yarn.sh



4. Vérifier que tout fonctionne (affiche la liste des processus Java) :

   jps



Si "jps" affiche bien NameNode, DataNode, SecondaryNameNode, ResourceManager 

et NodeManager, le cluster est prêt !
